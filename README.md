# Klassement

Competitiebeheer voor clubs: een multi-tenant webapp voor recreatieve zaalvoetbalcompetities.

- Regels en conventies: [`CLAUDE.md`](CLAUDE.md)
- Beslissingen en het waarom: [`docs/beslissingen.md`](docs/beslissingen.md)
- Voortgang: [`_progress.md`](_progress.md)

## Lokaal draaien
```bash
npm install
cp .env.example .env.local   # vul de keys van klassement-dev in
npm run dev
```

Controles: `npm run build`, `npm run lint`, `npm test`.
